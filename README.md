# Scientific Calculator
This is a simple calculator that can solve basic problems. It also has a fun generator that displays facts about math and calculators.

# Features
- Basic operation buttons
- Clear button
- All clear button
- Fact generator

# Tools used
- HTML
- CSS
- JavaScript
- https://tenrandomfacts.com/calculator/
- https://facts.now/technology/electronics/39-facts-about-scientific-calculator/
- https://whizz.com/blog/20-cool-facts-maths/

# Challenges/Learned
- I learned how to create functions for the different operators buttons
- A challenge I faced was figuring out the little errors that were made in the making of this project such as incorrect name, buttons clicks, and incorrect conversion for operators
